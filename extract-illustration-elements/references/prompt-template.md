# 单元素编辑提示词模板

对每个元素单独填写。保持简短、位置明确，并重复保真边界。

```text
用途：background-extraction
素材类型：用于贴纸或冰箱贴的独立插画元素
输入图：图 1 是编辑目标，也是唯一的设计依据。

目标：
只提取位于【画面位置】的【元素名称】。删除所有其他场景内容，并补全该元素因【遮挡物/画面裁切】而缺失的【具体部位】，生成完整、独立的单元素素材。

保真边界：
严格保留原图中可见的【轮廓、五官、姿势、比例、服装、纹样、配色、饰品】。保持【水彩/彩铅等】的笔触、颜料颗粒、纸面质感、半透明晕染和手绘边缘。不要重新设计、修饰、美化或简化可见部分。

补全边界：
只推断原图确实看不到的【缺失部分】。沿用已知结构、对称关系和原姿势，采用最保守、最简单的完整形态。不要增加没有依据的花纹、文字、配件、道具或动作。

构图与输出：
只出现一个元素；保持原视角和原姿势；完整显示；居中；四周留出透明安全边距；不裁切。输出真实透明 Alpha，不要白底，不要绘制棋盘格。

禁止：
背景碎片、地面、投影、其他角色或道具、额外肢体、重复结构、五官变化、比例变化、姿势变化、风格漂移、矢量化、3D 化、照片化、文字、Logo、水印、装饰边框。
```

## 低置信度补全

缺失结构存在两种合理解释时，在同一保真边界下分别生成方案 A 与 B。只改变不确定区域，其他条件完全一致。不要用随机变化充当结构方案。

## 透明失败后的纯色背景版本

仅在真实 Alpha 连续失败时，把输出要求替换为：

```text
背景必须是单一、完全平坦、无纹理、无渐变的高饱和纯色，并与主体所有颜色明显不同。主体与背景之间不要投影、辉光或环境反射。禁止棋盘格、纸纹和场景内容。
```

生成后再用 `key_background.py` 去除纯色；不要对原始扫描图使用此流程。
