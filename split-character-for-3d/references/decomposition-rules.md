## 输入可靠性

先判断输入能够支持什么级别的结果：

- **单张三分之四视图**：可可靠判断可见轮廓、正面连接和主要遮挡；不可可靠恢复完整背面。
- **正背双视图**：可判断主要前后结构；侧面厚度与交叉关系仍可能不确定。
- **正背左右四视图**：可规划严格部件多视图，但仍需检查各视图是否本身一致。
- **同一角色的多张动态图**：只作为结构补充，不得混合不同姿势生成伪一致部件。

参考图彼此冲突时，先指出冲突并指定主参考图。不要平均融合互相矛盾的结构。

## 拆分候选评估

优先采用同时满足多项条件的边界：

- 已有明确接缝、层叠关系或结构转折。
- 拆开后两侧都形成清晰、连贯的体块。
- 能明显减少遮挡、穿插或细长结构对图生三维的干扰。
- 有单一、清楚的分离或拼装方向。
- 接缝能被衣领、腰带、甲片、发饰或其他原设计隐藏。

降低或拒绝以下候选：

- 横穿脸、手、主要纹样或光滑裸露肌肉。
- 产生尺寸很小、没有独立建模价值的碎件。
- 要求大面积凭空补完不可见设计。
- 导致同一结构在两个部件中重复或必须互相穿透。
- 只是颜色、材质、阴影或普通表面曲率发生变化。

## 常用拆分层级

把这些作为候选模板，不要机械套用：

- **两件式**：上半身 / 下半身。优先沿腰带、束带、胸甲与裙甲交界切分。
- **三件式**：头部 / 上半身 / 下半身。适合优先保留面部细节的角色或雕像。
- **四至六件式**：头部 / 躯干与主要手臂 / 下半身 / 武器 / 大型飘带或披风 / 底座。
- **复杂角色**：只在手臂、翅膀、长发、尾巴或大型装饰严重遮挡主体时继续拆分。

用户指定准确数量时，把模板降为参考，并确保所有结构只分配一次。

## 部位规则

### 头部与颈部

- 为保留面部细节，优先考虑沿项圈、颈环、头盔下沿或发饰连接处分离。
- 避免在下颌、胡须、发丝和脸侧装饰密集区域切开。
- 长发若与背部大面积融合，可将头发主体留给躯干，把头脸作为独立件；必须在拆分表中明确归属。

### 躯干与下半身

- 首选腰带、腹甲下缘、裙甲上缘、衣物束带或已有水平叠层。
- 避免把连续的大型兽面纹、胸腹雕刻或主要衣褶从中切断。
- 动态扭腰角色应沿真实衣甲交界切分，不要强行使用世界坐标水平切面。

### 手臂与手

- 只有在肩甲、袖口、护腕等位置存在自然边界，或手臂严重遮挡躯干时才独立拆分。
- 默认把手与前臂放在同一部件，避免切割手掌或手指。
- 双手交叠或抱持物体时，先确定每只手的唯一归属，再决定武器是否独立。

### 腿与脚

- 默认把骨盆、裙摆主体和双腿保留为一个下半身部件，以维持站姿关系。
- 只有交叉腿、极端动态或打印体积限制明确要求时才拆开左右腿。
- 保持脚底接地逻辑和前后关系，不因分件把踮脚改成平脚或交换左右腿。

### 武器与手持物

- 刚性、长直且具有独立轮廓的武器通常独立，有利于图生三维。
- 手掌和手指通常归属角色身体；武器连接处保留清晰握持空间，不生成第二套手指。
- 如果手和武器在原图中完全融合且单图无法推断握持结构，标记风险，不假装精确恢复。

### 飘带、披风、长发与尾巴

- 当其细长、悬空、自交叉或遮挡身体时，优先作为独立件。
- 当其与躯干大面积贴合且拆开会要求大面积补完背面时，保留在主体部件。
- 跨越上下半身的装饰要么整体归属连接更强的一侧，要么独立；禁止在两侧重复完整装饰。

### 盔甲与服装层

- 不因每块甲片可见就逐片拆分。只有甲片本身是独立硬壳、严重遮挡底层或用户要求模块化时才拆。
- 连续布料通常随身体体块保留；大型外套、披风或裙撑可以独立。

### 底座

- 底座通常独立，尤其当其几何简单、材质不同或遮挡脚底时。
- 若用户要求严格限制部件数，可以把底座并入下半身，但必须说明这会降低脚底生成质量。

## 遮挡与未知区域

- 只补全为形成闭合体块所必需的连接面和局部遮挡面。
- 延续邻近已知材质、厚度和结构方向；不要新增纹样、甲片或解剖细节。
- 对完全不可见的大面积背面，保持未决或请求补充参考，不要将推断包装为事实。
- 当单张图无法判断某结构属于前景还是背景部件时，在生成前提出一个聚焦问题，或在方案中标注两种可能。

## 部件数量控制

每增加一个部件，都检查它是否至少带来一种明确收益：

- 保存高价值细节；
- 消除严重遮挡；
- 隔离刚性附件；
- 改善图生三维轮廓；
- 提供明确装配方向。

没有这些收益时，不增加部件。默认追求“最少但足够”的拆分，而不是最大数量。
