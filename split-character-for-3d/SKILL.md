# 角色模型部件拆分

## 目标

把角色参考图转换为适合独立生成三维模型的部件方案与参考图。优先保证原角色的姿势、比例、轮廓、服装结构、表面细节和部件归属；不要把“拆分”变成重新设计。

## 核心流程

1. 检查全部输入图，确认它们是否表现同一角色、同一姿势和同一套结构。生成或编辑图像前，先目视检查参考图；有本地路径时使用图像查看工具。
2. 提取用户的硬约束：指定部件、部件数量、保留姿势、输出视角、背景、目标三维工具和禁止修改项。把明确指令视为最高优先级。
3. 判断执行模式：
   - 用户已明确部件数量或边界时，直接分析并生成，不重复确认。
   - 用户未明确拆法时，先给出一个简洁方案并等待确认，再生成图像。
   - 只缺打印工艺、尺寸或公差时，不阻塞面向 AI 建模的视觉拆分。
4. 按自然结构规划部件。需要详细判断时读取 [decomposition-rules.md](references/decomposition-rules.md)。
5. 先输出拆分表，再使用可用的图像生成/编辑工具制作拆件图。需要组装提示词时读取 [image-generation-templates.md](references/image-generation-templates.md)。不要用普通绘图脚本伪造图像编辑结果。
6. 检查所有原始几何是否恰好归属一个部件，并检查有无漏件、重件、跨部件粘连、比例漂移或姿势改变。

## 拆分原则

按以下优先级做取舍：

1. 保住身份特征、面部细节、整体动态和主要轮廓。
2. 让每个部件成为语义完整、轮廓清楚、适合单独生成三维模型的闭合体块。
3. 沿领口、腰带、甲片接缝、袖口、护腕、靴口、发饰连接处等自然边界切分。
4. 通过拆分降低自遮挡、交叉穿插、狭窄负空间和细长附属物对图生三维的干扰。
5. 控制部件数量；不要为了展示细节而随机切碎连续形体。

不要仅依据颜色、材质、明暗或普通曲率变化拆件。普通褶皱、倒角和连续曲面不构成独立部件。

## 边界与部件归属

- 为每个原始结构指定唯一归属，禁止在相邻部件中重复手、衣摆、甲片、头发、飘带或武器。
- 优先把切口藏在已有结构缝中；避免横切面部、手指、主要纹样和角色辨识度最高的轮廓。
- 将切口补成简洁、闭合、近似平整的中性连接面。除非用户明确要求，不添加卡榫、插孔、磁铁槽或虚构内部机械结构。
- 对跨越多个身体区域的飘带、披风、长发和武器，依据较大连接面积、独立生成收益和装配方向确定归属；无法干净归属时，把它列为独立部件或先提示冲突。
- 用户指定较少部件时，服从数量约束，并说明由此产生的遮挡、穿插或细节损失风险；不要擅自增加部件。

## 输出拆分表

在生成图像前或与图像一起，给出简短表格：

| 字段 | 内容 |
|---|---|
| 部件 | 清晰、稳定的部件名称 |
| 包含结构 | 该部件拥有的原始几何 |
| 拆分边界 | 切口经过的自然结构 |
| 建议方向 | 分离或后续拼装方向 |
| 风险 | 遮挡、薄片、交叉或推断内容 |

部件明确且任务简单时保持表格简洁，不输出冗长教程。

## 图像输出

### 拆件总览图

- 把所有部件完整、互不接触地排列在同一张干净画布上，并保留足够间距。
- 默认使用纯白或极浅中性背景，不加文字、编号、箭头、水印、装饰边框或无关物体。
- 保持原始相机角度、姿势、比例、尺度关系、材质和表面细节。除分离与必要的连接面补全外，不改变设计。
- 保持每个部件边缘完整，避免裁切、遮挡、透明残影、悬浮碎屑和重复肢体。

### 独立部件参考图

当用户提到 Rodin、图生三维、AI 生成模型、逐件建模，或明确要求独立图片时：

- 为每个部件生成独立、居中、完整、背景干净的参考图。
- 使用一致的相机、尺度、光照与材质表现；不要为了“展示完整”而改变原姿势。
- 只补全因拆分而暴露的最低限度隐藏表面，并把不可见结构标记为推断内容。
- 让连接面闭合且容易识别，但不要声称二维生成图具有制造级尺寸精度。

### 多视图

- 输入包含可靠正、背、左、右视图时，保持同一部件、同一姿势、同一比例和一致结构，生成严格正交的部件多视图。
- 输入只有单张视图时，默认只生成同视角独立部件图。只有用户明确要求时才推断背面或侧面，并明确说明这是设计推断，不是从原图恢复的事实。
- 不把三分之四视角伪装成正交侧视图，不承诺单图生成的多视图绝对一致。

## 质量检查

交付前逐项确认：

- 部件数量与用户要求一致。
- 所有原始结构恰好出现一次。
- 原始姿势、比例、相机方向和主要轮廓未改变。
- 切口位于计划边界，连接面闭合，无血肉截面或无关内部结构。
- 相邻部件不粘连、不重叠，不出现多余连接桥。
- 手指、脚趾、面部、武器握持和细长饰物没有新增畸形。
- 单图不可见区域没有被描述成确定事实。

发现明显失败时，针对具体失败项重新编辑，不要通过泛化提示词整体重生成角色。

## 3D 打印扩展

只有用户明确需要制造级连接结构时，询问打印方式、成品尺寸、材料、装配方式和可接受接缝，再讨论壁厚、卡榫和公差。缺少这些参数时，可以标注建议连接区域，但不要虚构毫米数。

## 范围边界

处理人形角色、神像、雕塑、盔甲角色以及附属武器、服装、头发、披风和飘带。遇到机械、建筑或环境结构拆分时，说明需要结构类拆分 Skill，不要套用人体接缝逻辑。
