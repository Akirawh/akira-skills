# 东方天宫世界观生成器

## 用途

将简短创意扩展为统一世界观、神明尺度、具有电影摄影逻辑的东方天宫视觉方案。生成静帧提示词、视频提示词、镜头设计或连续分镜；也可诊断并改写已有提示词。

## 执行原则

1. 先提取用户已给出的主题、场景、人物、镜头、比例、时段、情绪、特殊元素、平台和输出数量。
2. 缺省项使用本技能默认值，不因非关键缺失而停止；只有人物身份、关键叙事或交付平台会实质改变结果时才简短询问。
3. 先确定叙事意图，再选择空间、尺度、镜头、光线、材质和动态；不要堆砌互不关联的华丽词汇。
4. 保持东方建筑结构可信、尺度关系可读、光源有动机、材质有物理差异。
5. 用户要求一组方案时，采用“九组差异化生成策略”；要求单条时，选最贴合叙事的一组。
6. 先输出适合目标平台的主提示词，再给负面词与必要参数。不要把多个平台的语法混入同一条可复制提示词。
7. 未指定语言时，以中文说明为主；需要模型识别稳定性时，可另附英文提示词，不做逐字硬译。

## 输入协议

接受自然语言或下列结构化输入；任一字段均可省略：

```yaml
主题: 天宫战争遗迹
场景: 破碎仙宫
人物: 一名白衣仙人，背影
镜头: 低机位远景
画幅: 16:9
时段: 黄昏
情绪: 庄严、寂静、劫后余生
特殊元素: 巨月、云瀑、残断天桥
平台: Flux
数量: 1
连续性: 单幅
禁用元素: 盔甲、人群
```

若未指定，使用：画幅 16:9、黄昏、超远景或远景、单一小人物、电影写实、低位云海、暖金主光、冷色环境光。

## 默认世界观

设定为九天之上的东方神域：巨大天宫群悬浮于低位云海之上，不属于人间文明，而是供神明、礼制与宇宙秩序使用的建筑。建筑体现东方木构、玉石台基、轴线礼制和留白，不照搬现实景区，也不混入现代城市语言。

根据用户主题覆盖默认设定；不得为了默认元素破坏明确剧情。

## 巨物尺度规则

- 让宫门达到数十至数百个人高，巨柱直径为人体数倍，台阶、屋檐、长廊和桥梁延伸至消失点。
- 使用人物、仙鹤、灯火、栏杆、门洞、云层或远山作为多级尺度参照；至少保留两级参照。
- 远景人物占画面高度 1%–4%，中景 5%–8%，近景 12%–20%。除非用户明确要求，人物不抢占建筑主体。
- 以遮挡、透视收缩、空气透视和重复结构表达体量，不只依赖“巨大、宏伟”等形容词。
- 避免门窗与人物比例冲突、远近物体同等清晰、重复柱网失真和无承重逻辑的结构。

## 建筑语言

从下列词库选择少量互相支持的元素，不要全量堆叠：

- 主建筑：白玉天宫、朱红神殿、月宫、星宫、云上祭坛、天庭长廊、浮空城、天门、观星台。
- 空间构件：巨柱、玉阶、月洞门、悬空桥、层叠屋檐、天河平台、巨型屏风、阙楼、回廊、藻井。
- 结构语法：中轴对称用于仪式与秩序；偏心构图用于旅程与未知；层层门框用于纵深；台基与柱网用于庄严。
- 装饰控制：纹样服务于等级和材质，避免满铺金饰、符号混杂、廉价“国潮”贴图。

## 自然系统

从叙事功能出发选择：

- 云海用于隔绝人间与隐藏基座；云瀑用于垂直动势。
- 巨月用于静谧、孤独或神圣尺度；银河与天河用于宇宙秩序和引导线。
- 神山与巨松用于建立东方山水层次；仙鹤用于尺度和生命感。
- 风、雾、雪、雨、尘埃、花瓣、旗幡只在能揭示空间或情绪时加入。
- 自然元素与建筑共享光向、风向和透视，不做独立贴图式装饰。

## 人物规则

- 默认使用背影、斜后方或越肩视角，让人物承担尺度锚点和叙事入口。
- 明确服装轮廓、姿态、视线方向和与环境的关系；减少无意义面部细节。
- 单人用于孤独、朝圣、探索；少量仪仗用于秩序；战争场景可增加人群，但保持层级和队形。
- 连续分镜中固定人物身份、服色、发型、道具、身高比例和运动方向。
- 若用户明确要求肖像或角色主导，可突破默认比例，并说明建筑转为环境叙事。

## 摄影与光影

- 默认采用大画幅电影摄影观感、24mm 广角、真实物理光照、空气透视、体积光和高动态范围。
- “ARRI Alexa 65”“IMAX”“Unreal Engine 5”“8K”等仅在目标模型确实受益时使用；不要用品牌词替代镜头设计。
- 低机位仰拍强调威严；高机位俯瞰强调体系；平视长镜头强调旅程；越肩镜头强调发现。
- 默认光线：黄昏低位太阳形成暖金漫射主光，冷色天空补光，建筑边缘出现克制轮廓光，云层产生有方向的体积光。
- 夜景需给出可信光源，如月光、宫灯、星河反射；避免无来源的全局发光。
- 视频镜头给出起点、运动、终点、前中后景视差和时长感，限制不必要的摇摆与快速变焦。

## 材质规则

- 白玉：温润、微透光、细微矿物纹理、边缘磨损；避免塑料和均匀自发光。
- 木构：可见古木纹理、榫卯关系、朱红漆面与岁月痕迹；避免光滑玩具质感。
- 琉璃瓦：沿曲面反射天光，粗糙度有变化；避免镜面金属屋顶。
- 金属：用于节点和礼器，呈现氧化、拉丝或锤纹，不大面积铺金。
- 云雾：有密度梯度、受光面和阴影面；避免棉花状重复纹理。
- 水体：表现反射、波纹、折射和表面张力，并与重力方向一致。
- 废墟：断口、灰尘、苔痕和结构受力相互吻合，不使用随机裂纹贴图。

## 构图原则

- 建立前景框架、中景叙事主体、远景世界延伸三层空间。
- 保留明确视觉焦点和呼吸区；每幅最多设置一个主奇观与两个辅助奇观。
- 使用廊柱、台阶、桥梁、天河或光束形成引导线；避免所有元素挤在画面中心。
- 仪式场景优先对称与中轴；探索场景优先偏心、遮挡和负空间；危机场景使用斜线、断裂和逆向动势。
- 建筑竖线保持稳定，广角畸变必须服务压迫感，不造成随意倾倒。
- 画面要能一眼回答：人物在哪里、要去哪里、世界有多大、此刻发生什么。

## 九组差异化生成策略

当用户要求九组、一组系列或未规定差异维度时，按以下九类生成。保持核心世界观和角色连续性，同时让叙事、空间、镜头、时段或动态至少两项显著不同。

1. **天门初见｜建立世界**：超远景或越肩视角；人物首次抵达巨型天门；强调门框套景、云海和尺度震撼。
2. **中轴朝圣｜秩序仪式**：正面对称、低机位、长玉阶；少量仪仗或单人沿中轴前行；强调礼制、节奏与庄严。
3. **云廊漫游｜空间纵深**：侧向长廊、重复柱网、消失点；平视跟拍或缓慢横移；强调风、衣摆和远景视差。
4. **月宫静夜｜诗性孤寂**：冷色夜景、巨月、白玉平台；单人小比例；强调负空间、月光反射和静止感。
5. **星河祭坛｜宇宙神圣**：高台或俯瞰，天河环绕祭坛；人物执行仪式；强调圆形秩序、星轨与可读光源。
6. **浮城全貌｜体系规模**：极高机位或航拍式推进；多层宫群、悬桥、神山共同构成城市体系；避免现代城市密度。
7. **云瀑奇境｜自然共生**：垂直构图或广角侧景；宫殿嵌入神山，云瀑穿越桥下；强调水雾、风向和层次。
8. **战争遗迹｜历史创伤**：破碎天桥、倾塌殿宇、熄灭宫灯；偏心构图与逆光；以结构断裂讲故事，避免纯粹脏乱。
9. **神迹降临｜叙事高潮**：光柱、天门开启或神兽掠过，但只保留一个核心神迹；低机位动态镜头；强调环境反应和人物敬畏。

若用户要同一场景的九种方案，可将九类视为镜头/情绪变奏；若要连续九镜，则按 1→2→3→4/5→6→7→8→9 组织发现、深入、转折和高潮，并补足镜头间动作衔接。

## 工作流

1. **解析**：把输入整理为“叙事目标、核心主体、尺度锚点、平台限制”。
2. **选型**：选择一种或九种策略，决定建筑、自然、人物、镜头和主光。
3. **构建空间**：依次写前景、中景、远景及其遮挡、透视和尺度关系。
4. **赋予物理性**：补充材质、光源、天气、风向与动态因果。
5. **平台适配**：压缩或展开提示词，添加平台支持的参数；不虚构版本参数。
6. **负面约束**：只列高风险问题和用户禁用项，避免与正向提示矛盾。
7. **检查**：执行质量清单；修复问题后再输出。

## 输出格式

默认采用：

```markdown
【作品名称】

【创意定位】一句话说明叙事与视觉重点。

【完整 Prompt】可直接复制到目标平台的主提示词。

【镜头设计】景别、机位、焦段感、构图、运动（静帧省略运动）。

【空间层次】前景 / 中景 / 远景。

【人物与尺度】人物姿态、占比、尺度参照。

【动态元素】仅视频或场景需要时输出。

【负面 Prompt】平台支持时给独立负面词；否则写为自然语言限制。

【平台参数】只给确定适用的参数；不确定版本时标注“按当前模型界面设置”。
```

九组方案时，每组输出“名称、差异点、完整 Prompt、负面 Prompt、参数”，最后给连续性总则。用户只要纯提示词时，省略解释字段。

## 负面提示词

按需选用并加入用户禁用项：

```text
现代建筑，现代城市，旅游景区摄影，普通尺度古建筑，小型宫殿，拥挤构图，元素堆砌，东西方建筑语汇混乱，廉价国潮装饰，卡通，动漫脸，低模，游戏界面，塑料材质，过度金色，自发光玉石，无来源光线，棉花云，重复纹理，结构悬空，透视错误，门窗比例错误，人物巨大，多余人物，肢体畸形，重复角色，文字，水印，标志，低清晰度，过度锐化
```

不要机械加入与画面无关的词。例如无人物风景无需列“肢体畸形”；废墟场景不要排除所有破损结构。

## 平台适配

### Midjourney

- 使用紧凑、层次清楚的自然语言，优先主体→环境→构图→光线→材质→风格。
- 用 `--ar` 指定画幅；仅在用户知道或指定版本时加入版本、风格化等参数。
- Midjourney 没有独立负面栏时，用 `--no` 放置少量明确对象，避免长串抽象质量词。

### Flux

- 使用完整描述句，明确空间关系、材质和光源；避免大量逗号标签与相互矛盾的风格词。
- 把限制写成可观察的正向约束；若界面支持独立负面栏，再提供负面词。
- 对文字、人数、方位等要求保持简洁且具体。

### SDXL

- 分离正向与负向提示词；可按主体、环境、摄影、质量组织标签或短句。
- 权重语法、采样器、步数、CFG 和分辨率依具体前端与模型而定，不假定通用最佳值。
- 使用写实模型时减少引擎名与互相冲突的艺术家风格词。

### 即梦

- 优先清晰中文描述，明确主体、景别、动作、环境、光影、画幅和风格。
- 视频任务补充镜头运动、主体运动、环境运动与稳定性限制。
- 参数名称随产品版本变化时，写“在界面选择对应画幅/时长/运镜”。

### 可灵

- 按“首帧场景—主体动作—镜头运动—环境响应—结尾状态”描述视频。
- 控制单镜头动作数量，写清速度、方向、幅度和前后景视差。
- 图生视频时锁定建筑结构、人物服装与光向，避免新增无关物体。

### Runway

- 使用视觉可见、可拍摄的运动描述；少写抽象审美标签，多写摄像机和物体如何移动。
- 区分镜头运动与主体运动，给出稳定、连续、无形变等限制。
- 以当前界面支持为准设置时长、比例和运动控制，不虚构命令参数。

### AI 漫剧分镜

- 为每镜输出镜号、时长、景别、画面、角色动作、台词/旁白、音效、转场和连续性锚点。
- 相邻镜头遵守视线、运动方向和轴线连续；需要越轴时安排中性镜头。
- 每镜只承载一个主要叙事动作；为角色和关键场景建立固定描述串并重复使用。
- 九镜可映射为：建立世界→抵达→深入→发现→仪式→全貌→异变→遗迹真相→神迹高潮。

### 示例输出

【作品名称】《月蚀之后》

【创意定位】一名幸存者穿过沉寂神域，以极小人物与断裂巨构表现劫后余生。

【完整 Prompt】电影写实的东方神域战争遗迹，黄昏将尽，一名白衣仙人背对镜头站在断裂的白玉天桥边缘，人物仅占画面高度约 3%；前景是带有真实断口、灰尘和磨损的玉石栏杆，中景为倾塌的朱红神殿、直径数倍于人体的巨柱和延伸至云海的残破玉阶，远景一轮被薄云遮蔽的巨月悬于神山之后，云瀑从浮空宫殿基座垂落。24mm 广角感，低机位偏心构图，桥梁指向远方宫门，冷蓝环境光与最后一束暖金侧逆光共同塑造体积雾和克制轮廓光；温润微透的白玉、斑驳朱漆、低反射琉璃瓦，真实空气透视，庄严、寂静、劫后余生，物理可信的电影画面。

【镜头设计】超远景，低机位，24mm 广角感；人物位于左下三分点，断桥形成通往月宫的引导线。

【空间层次】前景断栏与碎石；中景人物、断桥和倾塌神殿；远景巨月、神山、云海与云瀑。

【人物与尺度】白衣仙人背影，占画面高度约 3%；栏杆、柱径、门洞和宫灯形成递进尺度参照。

【负面 Prompt】现代城市，旅游景区，普通尺度宫殿，人物过大，拥挤构图，过度金色，塑料玉石，无来源发光，随机裂纹，结构失真，棉花云，卡通，文字，水印。

## 质量检查清单

输出前逐项检查；任何关键项失败都要先改写：

- [ ] 叙事焦点可用一句话说明，且画面只有一个主奇观。
- [ ] 东方建筑语汇统一，结构、台基、柱网、屋檐和受力关系可信。
- [ ] 至少有两级尺度参照，人物比例符合景别目的。
- [ ] 前景、中景、远景明确，遮挡、消失点和空气透视共同建立纵深。
- [ ] 人物姿态、视线和位置服务叙事，不无故抢占主体。
- [ ] 主光、补光、轮廓光均有可信来源，天空、云、水和建筑受光一致。
- [ ] 玉、木、瓦、金属、云、水的质感可区分，不呈现塑料或均匀发光。
- [ ] 自然和动态元素有明确方向、速度或叙事作用，不是装饰堆砌。
