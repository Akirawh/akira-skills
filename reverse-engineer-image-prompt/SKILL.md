# 图像提示词反推

## 目标

从参考图中提炼真正控制生成结果的视觉变量，输出简洁、准确、可直接使用的中文提示词。保留原图的主体关系、视觉层级、构图、镜头、光影、色彩与风格，不把反推变成逐物清点、剧情扩写或形容词堆砌。

## 核心流程

1. 先目视检查全部输入图。存在本地路径时使用图像查看工具；不要仅依赖文件名、OCR、自动标签或用户的简短描述。
2. 提取硬约束：目标平台、需要复刻的范围、必须保留或排除的内容、输出语言、画幅和长度。用户未指定时，默认复刻整体视觉效果并输出中文。
3. 判断主要图像类型并调整重心：
   - 人物或角色：优先身份特征、姿势、轮廓、表情、服装与人物所占画幅。
   - 场景或建筑：优先空间层级、尺度参照、动线、主轮廓、景深与气氛。
   - 道具或产品：优先外形比例、展示角度、主要材质、布光与背景控制。
   - 平面设计或插画：优先版式、形状语言、线条、媒介、色块关系与完成方式。
4. 给可见信息分级，不把八个维度机械地写成同等篇幅：
   - **核心锚点**：改变后会让画面失去身份或构图特征的信息，必须进入提示词。
   - **强化信息**：支撑材质、空间、气氛和风格的信息，择要进入提示词。
   - **可删噪声**：偶然小物、重复装饰、压缩瑕疵、不可确认细节，默认省略。
5. 按八个维度完成简短拆解，再按视觉优先级重组提示词；不要照着八个标题逐段拼接。
6. 只写可见或有充分依据的信息。对焦段、软件、渲染器、画师、隐藏结构和被遮挡内容无法确认时，使用描述性近似词或直接省略，不伪造精确结论。
7. 根据这张图最可能出现的偏差生成负面提示词，最后检查正负提示之间是否矛盾。

## 八维拆解规则

| 维度 | 提取真正有控制力的信息 |
| --- | --- |
| 主体特征 | 主体类别、数量、年龄段或形态、体态比例、姿势动作、朝向、表情、服装或关键轮廓；用可见特征替代“好看、酷、震撼”等空泛评价。 |
| 构图方式 | 横竖画幅、主体位置与占比、裁切范围、对称或偏心、前中后景、引导线、负空间、尺度对比和视觉焦点。 |
| 镜头角度 | 正交或透视、相机高度、俯仰与侧转、远中近景、广角或长焦倾向、透视强弱、景深；没有依据时不要虚构精确毫米数。 |
| 光线方向 | 主光的方向与高度、软硬、冷暖、明暗反差、补光、轮廓光、体积光和曝光倾向；优先描述光如何塑造主体。 |
| 色彩搭配 | 主要色、辅助色与点缀色，饱和度、明度、冷暖关系及其在主体和背景中的分布；通常保留二至四个关键色组。 |
| 材质细节 | 二至四种主要材质及其粗糙度、高光、透光、磨损、纹理尺度和边缘状态；不要把所有表面小细节逐项罗列。 |
| 画面风格 | 媒介或渲染类型、写实程度、造型语言、线条或笔触、细节密度、后期特征；默认用视觉属性描述，不用无法证实的画师名代替分析。 |
| 背景元素 | 场所类型、空间层次、支撑构图的关键物、天气、烟雾、粒子和虚实关系；省略不影响主体和氛围的杂物。 |

## 组织最终提示词

按以下顺序组织内容，但只保留对当前图片有用的项目：

1. 主体、关键特征与动作。
2. 构图、景别、相机位置与透视。
3. 主光、明暗关系与核心配色。
4. 主要材质、视觉风格与完成方式。
5. 背景层次、气氛与必要的清晰度要求。

把高优先级信息放在前面，使用六至九个逗号分隔的短语组成一段自然中文。默认长度遵守以下预算：

- 简单头像、单体道具或产品图：约 100—180 个中文字符。
- 复杂角色、建筑或场景图：约 180—300 个中文字符。
- 除非用户要求详细版，否则不要超过约 320 个中文字符。

删除同义重复、解释原因、主观赞美和关键词噪声。不要用“杰作、顶级、最佳质量、8K、极致细节”等词替代具体控制条件；只在确有作用时写“边缘清晰、层次分明、材质分离明确、微表面细节可读”等可观察目标。

## 负面提示词

从实际风险中选择四至八个短语，例如：主体数量错误、姿势改变、比例失衡、透视畸变、重复肢体、结构粘连、背景喧宾夺主、光向错误、过曝、文字或水印。不要每次复制同一套万能负面词，也不要禁止正向提示明确要求的内容。

## 平台与多图适配

- 用户指定生成平台时，采用该平台适合的自然语言和字段结构；只有确认平台支持时才加入权重、参数或专用语法。
- 用户未指定平台时，输出通用中文提示词，把画面比例与负面提示词单独列出，不添加模型专属参数。
- 多张图表现同一对象的不同角度时，提取稳定不变的结构，不把不同镜头平均成一个含混视角。
- 多张图分别承担主体、构图或风格参考时，按用户指定的角色组合；若参考之间存在会改变结果的冲突且没有主次，先询问哪张图主导。
- 不要因为用户上传了图片就自动生成或编辑图片；只有用户明确要求出图时才调用图像生成或编辑工具。

## 默认输出格式

### 八维拆解

使用两列表格列出八个维度。每格只写一条关键结论，默认控制在约 15—35 个中文字符，不展开成教程。

### 完整提示词

输出一段可直接复制的中文提示词，不在提示词内部解释判断过程。

### 建议设置

用一行分别给出“画面比例：…；清晰度：…；质感：…”，不要把三项合并成空泛的质量标签；用另一行给出负面提示词。画面比例优先沿用输入图，无法精确判断时标注为近似比例。

如果用户说“简短一点”“只要提示词”或“不要分析”，省略八维表格，只输出完整提示词、画面比例和负面提示词。用户只要正向提示词时，严格只给正向提示词。

## 交付前检查

- 确认提示词描述的是生成控制变量，而不是图片内容清单。
- 确认核心锚点出现在前半段，次要装饰没有挤占篇幅。
- 排除“全身但近景裁切”“低机位但俯拍”“柔光但硬阴影”等内部冲突。
- 排除无依据的精确焦段、软件、作者、隐藏结构和剧情设定。
- 确认比例、清晰度、材质、背景和负面约束与原图及用户目标一致。
- 确认最终提示词符合长度预算，且没有为了显得专业而堆砌术语。
