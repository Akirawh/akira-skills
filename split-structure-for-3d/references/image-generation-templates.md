## 使用方法

把模板当作提示模块，依据资产类型、层级、部件清单、画布比例和用户约束改写。不要原样输出占位符。编辑参考图时，把保真约束放在提示词前半段，并明确每个结构的唯一归属、模块复用和不可推断区域。

## 结构归属分色图

```text
以输入参考图为唯一几何依据，保持资产完整装配、原始比例、原始视角和全部轮廓不变。按照以下确认后的结构部件进行 ID 分色：[部件与边界清单]。

每个独立结构部件使用一种唯一的高饱和度纯色，相邻部件色相明显不同。同一连续部件无论朝向和曲率如何变化都保持同一种颜色；重复模块的不同实例可保持同色，仅在需要区分唯一实例时使用不同颜色。

使用无纹理、无渐变、无高光、无阴影、无环境色的平涂 vertex color / ID color render。禁止根据原材质、污渍、光照和普通倒角制造新边界。禁止改变或移动任何几何，不添加文字、编号和图例。
```

## 通用拆件总览图

```text
以输入参考图为唯一造型依据，把同一个[机械或建筑]资产拆分为以下一级总成和部件：[分层清单与唯一归属]。

严格保持原图的设计、结构层级、轮廓、相对尺寸、世界向上方向、表面细节、材质、破损和原始相机角度。只执行部件分离和最低限度连接面补全，不重新设计资产，不补造不可见内部。

按总成或模块族将所有部件完整排列在同一张[画布比例]画布上，彼此留出明确空隙，互不接触、互不遮挡。每个原始结构只出现一次。切口严格位于：[接缝与边界清单]。暴露区域补成简洁、闭合的中性连接面。

纯白干净背景，均匀中性光照，无文字、编号、箭头、水印、边框和无关物体。保持部件尺度关系，不任意旋转以迁就排版。
```

## 机械总成爆炸图

```text
将机械资产按以下层级拆开：[主体总成、功能总成、外壳附件、连接件]。沿真实装配轴、滑轨、法兰、铰链和面板缝分离，保持各部件方向与原装配状态一致，形成清楚但克制的爆炸排列。

保留所有可见面板、管线、关节、磨损和制造细节。禁止新增发动机、齿轮、液压机构、螺丝、舱室或看不见的底盘结构。重复轮组、履带片或叶片只展示规范模块，除非用户要求还原全部实例。
```

## 建筑模块拆分图

```text
将建筑资产按以下层级拆分：[基座、主体分区、柱梁墙、门窗、屋顶、楼梯栏杆、装饰与独特变体]。保持共同世界向上方向、建筑网格、层高、开间、坡向和原始相机角度。

重复柱、标准墙板、窗、瓦片和栏杆段只展示一个规范模块；转角、端头、洞口和大型破损展示独特变体。禁止从单张立面新增楼层、房间、背立面、屋架、门窗和装饰。禁止修复原图中的崩塌与缺口。
```

## 独立部件或规范模块

```text
从输入参考图中仅保留并分离[部件或规范模块名称]，该部件包含：[唯一归属结构]。删除其他结构，但不得改变该部件原有的角度、比例、轮廓、厚度线索、表面细节、材质和相机方向。

沿[拆分边界]形成干净、闭合的中性连接面。只补全拆分后必须可见的最低限度隐藏表面，延续邻近已知结构，不新增面板、管线、紧固件、房间、门窗、纹样或内部机构。

部件单独居中并完整入镜，纯白背景，均匀中性光照，边缘清晰，无文字、编号、箭头、支架和无关内容。与同组其他部件保持相同尺度、世界向上方向、相机和材质表现。
```

## 可靠多视图输入

仅在输入确实包含一致的正、背、左、右视图或多个可靠立面时使用：

```text
依据输入多视图，仅提取[部件名称]并制作同一几何的严格正交视图：正面、背面、左侧、右侧。所有视图必须保持同一结构、同一比例、同一边界、同一孔洞与附件数量和同一尺度。无透视、无广角、无三分之四视角；基准线和世界向上方向一致。
```

## 单图推断多视图

只有用户明确接受设计推断时使用：

```text
以输入单张参考图为主要造型依据，为[部件名称]推断设计一致的其他视图。严格保留可见结构；不可见区域采用最少设计原则，延续已知厚度、模块节奏、材质和构造方向，不新增主要功能、房间、机构或装饰。输出为建模概念参考，不声称是原始资产的精确恢复。
```

在文字答复中明确标注推断视图，不能只把免责声明藏在生成提示词里。

## 局部失败修复

不要因一个局部错误重画整个资产。使用定点修复描述：

```text
仅修复[具体总成、模块或区域]：[具体错误]。保持画面其他区域、所有其他部件、结构层级、比例、视角、世界向上方向、材质和排列完全不变。将该区域调整为：[可验证目标]。禁止添加任何未要求内容。
```

常见目标包括：分开粘连面板、恢复正确运动轴、补回遗漏梁柱、移除重复管线、恢复屋顶坡向、让连接面闭合、消除跨部件连接桥。

## 必须加入的负面约束

依据任务选择并融入正向提示，不要只堆砌孤立关键词：

```text
禁止重新设计，禁止改变原始视角，禁止改变世界向上方向，禁止改变比例和模块节奏，禁止增加或删除原始结构，禁止重复部件，禁止漏件，禁止跨部件粘连，禁止透明残影，禁止多余连接桥，禁止随机切碎连续曲面，禁止新增内部机械、房间、楼层、门窗和装饰，禁止修复原始破损，禁止文字、标签、编号、箭头、水印和无关背景物体。
```
