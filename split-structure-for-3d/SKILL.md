# 机械与建筑模型部件拆分

## 目标

把机械或建筑参考图转换为适合独立生成三维模型、模块化制作和后续拼装的部件方案与参考图。优先保持原设计、尺度关系、结构层级、模块复用与连接逻辑；不要把“拆件”变成重新设计或凭空补造内部结构。

## 路线选择

先判断资产类型，再读取对应规则：

- **机械路线**：机械装置、车辆、设备、机甲非角色部件、硬表面道具、可动机构。读取 [mechanical-decomposition.md](references/mechanical-decomposition.md)。
- **建筑路线**：建筑单体、门楼、塔楼、墙体、屋顶、台阶、遗迹和模块化场景资产。读取 [architecture-decomposition.md](references/architecture-decomposition.md)。
- **混合路线**：建筑主体附带大型机械系统时，先按建筑层级拆主体，再对独立机械总成使用机械规则。不要把两套路由混成一张无层级的零件清单。
- **范围外**：人形角色、服装、毛发和人物雕像改用角色拆分 Skill；建筑上的人物雕像本体也按角色处理。

## 核心流程

1. 检查全部输入图，确认它们是否表现同一资产、同一版本和兼容的结构。生成或编辑图像前先目视检查参考图；有本地路径时使用图像查看工具。
2. 提取用户的硬约束：指定部件、部件数量、保留视角、输出类型、背景、目标三维工具、模块粒度和禁止修改项。把明确指令视为最高优先级。
3. 判断执行模式：
   - 用户已明确部件数量或边界时，直接分析并生成，不重复确认。
   - 用户未明确拆法时，先给出一个简洁分层方案并等待确认，再生成图像。
   - 只缺打印、加工或公差参数时，不阻塞面向 AI 建模的视觉拆分。
4. 建立层级：先划分总成或模块族，再决定是否继续拆成子部件。不要把所有可见细节放在同一层级。
5. 为每个原始结构指定唯一归属，并区分唯一件、重复模块和实例。重复件默认只建立一个规范模块，除非每个实例具有不可复用的形变或破损。
6. 先输出拆分表，再使用可用的图像生成/编辑工具制作拆件图。组装提示词时读取 [image-generation-templates.md](references/image-generation-templates.md)。不要用普通绘图脚本伪造图像编辑结果。
7. 检查有无漏件、重件、跨部件粘连、模块重复建模、比例漂移、视角改变或虚构结构。

## 通用拆分原则

按以下优先级做取舍：

1. 保住主轮廓、功能层级、建造逻辑、相对尺度和辨识度最高的结构。
2. 让每个部件或模块成为语义完整、轮廓清楚、适合单独生成三维模型的闭合体块。
3. 沿真实结构缝、面板缝、构造缝、伸缩缝、层级交界、连接法兰或明确穿插关系拆分。
4. 通过拆分降低遮挡、复杂穿插、狭窄负空间和细长附件对图生三维的干扰。
5. 优先复用重复模块；控制独立部件数量，追求“最少但足够”。

不要仅依据颜色、材质、污渍、光照阴影、普通倒角或连续曲率变化拆件。不要因为表面存在纹理分区，就假设那里存在真实结构缝。

## 边界、坐标与归属

- 让每个原始结构恰好归属一个部件，禁止相邻部件重复拥有同一面板、管线、梁、瓦片、门框或装饰。
- 优先使用已有接缝和遮蔽边界；避免横切连续主梁、主要轮廓、完整浮雕和关键机械壳体。
- 将拆分后暴露的区域补成简洁、闭合的中性连接面。除非参考图可见或用户明确要求，不添加螺丝、铰链、卡扣、内部机械、房间或背面装饰。
- 保持统一世界向上方向、相机方向和相对尺度。拆件总览不得为了塞进画布而任意旋转每个部件。
- 记录明显的装配轴、运动轴、层叠方向或建筑网格；二维参考无法提供精确坐标时，不伪造数值。

## 输出拆分表

在生成图像前或与图像一起，给出简短表格：

| 字段 | 内容 |
|---|---|
| 总成或模块 | 稳定的层级名称 |
| 类型与作用 | 机械功能或建筑构造角色 |
| 包含结构 | 该部件唯一拥有的几何 |
| 拆分边界 | 接缝、层级交界或穿插关系 |
| 方向或网格 | 装配轴、运动轴、层叠方向或模块网格 |
| 复用 | 唯一件、规范模块、实例数量 |
| 风险 | 遮挡、薄片、未知内部或推断内容 |

任务简单时缩减字段，不输出冗长教程。复杂资产先列一级总成，再按需展开二级部件。

## 图像输出

### 结构归属分色图

当结构复杂、边界有歧义，或用户要求组件分色、vertex color、ID color render 时：

- 保持资产处于原始装配状态和原始视角，仅按确认后的结构部件分配唯一高饱和度纯色。
- 相邻部件使用明显不同色相；使用无纹理、无渐变、无高光、无阴影的平涂 ID 表现。
- 不依据原材质颜色重新切分，不用颜色制造不存在的接缝。
- 把分色图作为边界确认图，不把它冒充独立建模参考图。

### 拆件总览图

- 把部件按总成或模块族分组，完整、互不接触地排列在干净画布上。
- 部件较多时拆成多张层级板；不要把十几个零件压缩成无法用于建模的小缩略图。
- 默认使用纯白或极浅中性背景，不加文字、编号、箭头、水印、边框和无关物体。
- 保持原始视角、世界向上方向、比例、尺度关系、材质和表面细节。除分离和最低限度连接面补全外，不改变设计。

### 独立部件与规范模块

当用户提到 Rodin、图生三维、AI 生成模型、逐件建模或模块化制作时：

- 为每个唯一部件或规范模块生成独立、居中、完整、背景干净的参考图。
- 对重复构件默认生成一个规范模块，另在文字表格中记录实例数量；不要重复生成完全相同的柱、墙板、轮胎或瓦片。
- 使用一致的相机、尺度、光照和材质表现。只补全最低限度隐藏表面，不发明内部结构。
- 对破损、变形或风化显著不同的实例，说明它为何不能直接复用，再作为变体处理。

### 多视图

- 输入包含可靠正、背、左、右视图或建筑立面时，保持同一几何结构、同一比例、同一边界和一致尺度，生成严格正交多视图。
- 输入只有单张视图时，默认只生成同视角独立部件图。只有用户明确要求时才推断背面、内部或其他立面，并把结果标记为设计推断。
- 不把三分之四视角伪装成正交侧视，不从单张建筑正立面编造完整平面和背立面。

## 质量检查

交付前逐项确认：

- 部件数量、层级和用户要求一致。
- 所有原始结构恰好出现一次，重复模块没有被误当成大量唯一件。
- 原始视角、世界向上方向、比例、相对尺度和主要轮廓未改变。
- 边界位于真实接缝或确认位置，连接面闭合，无多余连接桥。
- 机械运动轴没有被错位，建筑柱梁墙屋顶关系没有被重排。
- 管线、栏杆、屋檐、瓦片和细长附件无粘连、缺失、重复或无意义碎片化。
- 不可见内部、背面、房间和机械原理没有被描述成确定事实。

发现局部失败时，针对具体部件与错误重新编辑，不要整体重生成资产。

## 制造与打印扩展

只有用户明确需要制造级连接结构时，询问打印或加工方式、成品尺寸、材料、装配方式和可接受接缝，再讨论壁厚、卡榫和公差。缺少这些参数时，可以标注建议连接区域，但不要虚构毫米数。

## 范围边界

处理机械、车辆、设备、硬表面装配体、建筑单体、建筑模块、遗迹和结构性场景资产。角色穿戴的盔甲若必须保持人体姿势与服装关系，使用角色 Skill；独立展示的机械盔甲零件可使用本 Skill。
